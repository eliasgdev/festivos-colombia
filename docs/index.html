Festivos de Colombia

    Los festivos marcados con «se corrió del…» se trasladan al lunes siguiente por la Ley 51 de 1983 (Ley Emiliani). Jueves y Viernes Santo no se trasladan.

    Úsalo en tu código

    Librería de JavaScript sin dependencias, con tipos para TypeScript. Funciona en Node 18+ y en el navegador.

    npm install github:eliasgdev/festivos-colombia
    import { festivos, esFestivo, sumarDiasHabiles } from 'festivos-colombia';

esFestivo('2026-11-16');               // true: Independencia de Cartagena
sumarDiasHabiles('2026-11-13', 1);     // '2026-11-17'
festivos(2027).length;                 // 18
